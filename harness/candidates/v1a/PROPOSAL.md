# v1a：快慢雙路徑（router）

父候選：v0

## 改了什麼
- `NUMERIC_TRIGGER=1`：問題有數字或問「幾／多少」，且沒用過計算機 → 觸發驗算（原本只看答案裡有沒有算式）
- `RECHECK_MODE=fresh`：驗算改成開新對話，只給「問題＋查到的文件」，不給草稿
- `RECHECK_THINK=1`：只有驗算那一步開思考模式；一般題目維持快速

## 為什麼（根據 v0 tune 錯題）
- 「A 年終幾個月」「35 歲每年健檢？」答案沒有算式 → 原本的檢查抓不到
- 「B+ 年終」被要求驗算後仍是 40,000 × 1.2：inline 重算時看得到自己的草稿，照抄錯的公式（n8n 實驗 n2→n3 的教訓）
- 「時薪 200 加班 3 小時」沒查文件、引用不存在的勞基法檔案，公式也沒分段
