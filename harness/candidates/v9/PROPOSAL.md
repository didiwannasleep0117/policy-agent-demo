# v9：把三種錯交給程式檢查（從 v8 來）

調整組剩下的錯（v8 38/42）：
1. 時薪 200 加班 3 小時：公式對，但 200×2×(1+1/3) 寫成 666.67（應為 533.33）→ 總數錯
2. 報帳撥款：答案對，但只看過片段沒讀全文
3. 出差預支旅費、旅遊補助預支：文件完全沒寫「預支」，模型自己推論可以／不可以

改法（都在 `agent/checks.py`，以開關控制）：
- ARITH_VERIFY：答案裡「算式＝數字」用安全計算機重算，算錯就把正確值附上退回一次
- CITE_READ：引用的文件只看過片段 → 程式呼叫 read_specific_document，把全文給模型核對後重寫
- TERM_CHECK：「可以…嗎」的問題，先請模型抽出想做的動作＋2–4 個規章常用同義寫法，程式檢查這些字有沒有出現在查到的條文；完全沒出現 → 回答找不到

為了不對調整組過擬合，另外加 3 題同類型、不同問法的新題（預支薪水、時薪 180 加班 4 小時、報銷款項幾號匯入），調整組變 45 題。
