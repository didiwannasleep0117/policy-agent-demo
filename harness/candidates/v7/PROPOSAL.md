# v7：v5 ＋ 是非題結論核對（SUPPORT_CHECK）

父候選：v5（v6 的 prompt 規則沒用，不採用）

## 改了什麼
- 是非題（可以嗎／有沒有／會不會）的回答不是拒答也不是找不到時，另開對話、開思考模式，請模型只做一件事：核對「條文有沒有明確支持這個結論」，用 JSON 回 supported。不支持就改成找不到的固定句

## 為什麼
- v6 在 prompt 寫「名單外的對象不要套用最接近的一列」，舅舅、姑姑、預支三題照錯（舅舅→比照、姑姑→算成祖父母、預支→自己推論成不可以）
- 經驗庫：8B 模型生成時不守規則，但「只核對、只回是非」比較容易做對；用程式強制執行結果
