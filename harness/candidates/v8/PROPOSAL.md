# v8：v5 ＋ 親屬稱謂由程式對照（KIN_CHECK）

父候選：v5（v6 prompt、v7 自我核對都不採用）

## 改了什麼
- 程式有一份「口語 → 條文用語」的親屬對照（太太→配偶、奶奶→祖父母、岳母→配偶之父母…）
- 問題是喪假／奠儀／婚育補助類，提到的親屬不在對照裡（舅舅、姑姑、叔叔、阿姨、表／堂兄弟姊妹…），回答卻不是找不到 → 改成「條文列出的親屬沒有 X」＋找不到固定句

## 為什麼
- 舅舅、姑姑兩題：v6 的 prompt 規則沒用；v7 的思考模式自我核對只救回舅舅，還讓平均時間變成 16 秒
- 跟 Text-to-SQL 的代碼對照同一個想法：容易猜錯的對照交給程式，不靠模型記規則
